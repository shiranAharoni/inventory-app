# Inventory Management App

A Full-Stack application designed for efficient stock tracking and management. This project serves as a robust example of connecting a modern **React** frontend with a **Node.js/Express** backend using **RESTful** architecture.

## 🚀 Overview
The Inventory App provides a centralized system to manage product data. It focuses on delivering a smooth user experience while ensuring data integrity between the client and the server.

## 🛠️ Tech Stack
* **Frontend:** React.js
* **Backend:** Node.js & Express.js
* **API Client:** Axios (Core) – used for handling all asynchronous communication.
* **Architecture:** REST API

## ✨ Key Features
* **Dynamic Inventory Tracking:** Real-time updates for product stock and details.
* **Full CRUD Support:** Complete flow for Creating, Reading, Updating, and Deleting inventory records.
* **Asynchronous Data Fetching:** Efficient state management using Axios to interact with backend services.
* **Responsive Design:** Optimized for a seamless experience across various screen sizes.

## 📡 Backend Architecture
The backend is built as a RESTful service, providing structured endpoints to support the frontend requirements. It handles:
* **Data persistence** and retrieval.
* **Middleware** for parsing and routing requests.
* **Standardized HTTP response codes** for error handling.


## ⚙️ Installation & Setup

1. **Clone the repository:**
   git clone https://github.com/shiranAharoni/inventory-app.git

**Backend & Tests:** Navigate to /backend and run npm install followed by npm start (or npm test to run logic validations). Note: Please ensure you have a local PostgreSQL instance running and update the .env file in the /backend folder with your credentials before starting the server

**Frontend:** Navigate to /frontend and run npm install followed by npm run dev.
